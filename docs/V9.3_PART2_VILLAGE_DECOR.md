# V9.3 Part 2 — Alderbrook Buildings & Decorations

This ZIP is an **overlay patch** for the already installed V9.3 Part 1. Extract its contents into the project root, replacing matching files; do not delete unrelated files.

- Replaces the existing procedural house and shop textures with more detailed **original code-drawn pixel art**.
- Adds original decorative fences, bushes, planters, and lanterns.
- Adds a more detailed shrine pedestal without changing the existing crystal interaction.
- Leaves gameplay, map geometry, existing collision rectangles, door interactions, quests, save logic, Whispering Woods, and touch controls unchanged.

No third-party assets were added in this patch.

## Test checklist

1. Start `python3 -m http.server 8000 --bind 0.0.0.0` from the project root and open `http://127.0.0.1:8000` in Safari.
2. Check cottages, teal-roofed shop, lanterns, flower planters and shrine.
3. Enter a building and return; talk to the Elder; interact with the shrine.
4. Move to Whispering Woods and back, and test Save.

**Note:** This ZIP does not include the V9.3 Part 1 files; apply it to the already upgraded project, not to a fresh V9.2e checkout.
