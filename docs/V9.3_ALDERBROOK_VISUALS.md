# V9.3 — Alderbrook Village Visual Upgrade

This is a visual-only update to the existing working V9.2e game.

## Changes
- Alderbrook grass and paths now use detailed pixel-art samples derived from the already credited Ansimuz forest artwork.
- Village trees use a green-canopy variant of the existing forest tree art.
- Road-edge details replace the previous flat dashed markings.
- The original village layout, buildings, NPCs, shrine, quests, interactions, collisions, and saving logic remain unchanged.
- Whispering Woods artwork is untouched.

## Credits
The village terrain and tree variants are recolored adaptations of the Ansimuz forest art already included in the project. See `assets/game/CREDITS.md` and the original license files.

## Installation (iPhone / iSH)
Unzip this patch and copy the `src/`, `assets/`, and `docs/` folders into the project root, merging folders and replacing matching files. Do not delete other project files.

## Testing checklist
1. Open Alderbrook and check grass, paths, trees, buildings, and crystal.
2. Talk to the Elder and inspect the crystal.
3. Enter and exit a house and the shop.
4. Enter Whispering Woods and verify forest visuals are unchanged.
5. Save, reload, and confirm progress resumes.

No changes to game mechanics are intended.
